## Art provenance

Forest and gold monogram generated for this project with `gpt_image_2_5_flare`, then processed locally into WebP and Android-density PNG assets. `tool/prepare_visuals.py` is an asset-authoring utility requiring original generated PNGs in the parent workspace; it is not required to compile or run the app. Final derived assets are committed. Original generated files: `degen-forest-v03.png`, `degen-icon-v03.png`.
